[Manual test plan](../../docs/v0.4-capability-matrix.md#manual-test-plan)
in under a minute.

## Why ffmpeg filter scripts and not native expressions?

ffmpeg 8's `drawbox` filter does **not** support per-frame expression
evaluation (its `t` parameter means "thickness", not time, and the `eval=frame`
option exists on `drawtext`/`drawgrid` but not on `drawbox`). The workaround
implemented in `scripts/gen_*.py` is to emit one `drawbox` filter per frame
with a fixed position, gated by `enable='eq(n,N)'`. The generated filtergraph
runs in milliseconds; the cost is only at filter-graph build time.
